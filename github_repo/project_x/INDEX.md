# PROJECT X: Story Index & Master Manifest

Welcome to **Project X** collaborative narrative studio. This index guides humans and AI agents (Gemini, Codex, Muse) through the project architecture.

## Structure Map:
- **`01_story/`**: The Manuscript
  - `full_story.md`: The complete compiled story from start to finish.
  - `chapters/`: Individual completed chapters (`chapter_01.md`, etc.).
  - `scenes/`: Active and approved scenes (`scene_01.md`, etc.).
- **`02_world/`**: The Worldbuilding Bible
  - `characters/`: Character dossiers, psychological profiles, relationships.
  - `powers/`: Abilities, magic system, combat capabilities, limits.
  - `maps/`: Geography, cities, key locations, realms.
  - `lore/`: Historical context, world history, background lore.
- **`03_director/`**: Direction & Guidelines
  - `goals/`: Plot milestones, story arc targets.
  - `rules/`: Literary rules, tone, formatting, style guide.
  - `scenarios/`: What-if branches, alternative scene variations.
- **`04_archive/`**: The Muse Vault (Maintained by Archive Agent Muse)
  - `past_sessions/`: Compressed transcripts from completed chat sessions.
  - `old_drafts/`: Superseded revisions and cutting-room floor text.
